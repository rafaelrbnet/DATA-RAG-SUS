# 06.2 - Normalização de Colunas (Modelo Canônico)

Documento de normalização aplicado no `src/data/transform.py` para a camada `data/processed/**/*.parquet`.

## 1. Regras Globais

- **Normalização de nomes (antes da transformação):** coalesce de colunas duplicadas após normalização para snake_case e aliases legados.
- **Tratamento textual padrão:** `trim`; `""`, `"nan"`, `"None"`, `"<NA>"` -> `null`.
- **Tipagem canônica:** por coluna (`boolean`, `Int64`, `Float64`, `string`) conforme tabela abaixo.
- **Modelo de saída:** parquet unificado por `ano/uf/mês` (SIA + SIH no mesmo arquivo).

Aliases legados aplicados:
- `year_comp -> ano_cmpt`
- `month_comp -> mes_cmpt`
- `system -> sistema`
- `uf -> uf_origem`
- `municip_res -> munic_res`
- `municip_mov -> munic_mov`
- `munResStatus/Tipo/Nome/Uf/Lat/Lon/Alt/Area -> mun_res_*`
- `pa_uf_mun -> pa_ufmun`
- `pa_mun_pcn -> pa_munpcn`
