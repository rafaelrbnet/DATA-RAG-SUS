# 06.1 - Domínio de Colunas (Modelo Técnico Consolidado)

Aqui está o descritivo técnico das colunas do dataset, consolidado a partir das definições oficiais do DATASUS e do schema canônico do pipeline (`data/processed`).

## 1. Colunas Padrão Comuns (Core)

Estas colunas identificam tempo, origem, categorização clínica básica e georreferência de residência.

| Coluna | Descrição |
|---|---|
| `ano_cmpt` / `mes_cmpt` | Ano e mês de competência do dado processado. |
| `sistema` | Origem do dado: `SIA` (Ambulatorial) ou `SIH` (Hospitalar). |
| `uf_origem` | Unidade da Federação de origem (`UF` em sigla de 2 letras), com validação no padrão IBGE. |
| `main_icd` | Código da doença principal (CID-10) padronizado pelo pipeline (maiúsculo, sem ponto e com validação de formato). |
| `icd_group` | Agrupamento CID-10 em nível de capítulo/faixa (ex.: `J00-J99`, `I00-I99`). |
| `opm_flag` / `fisio_flag` | Indicadores booleanos para OPM e fisioterapia. |
| `mun_res_status`, `mun_res_tipo`, `mun_res_nome`, `mun_res_uf`, `mun_res_lat`, `mun_res_lon`, `mun_res_alt`, `mun_res_area`, `mun_res_zona` | Dados geográficos e de zona do município de residência. |

## 2. Colunas Específicas: SIA (Ambulatorial)

Focadas em produção ambulatorial, profissional, procedimento SIGTAP e faturamento.

| Coluna | Descrição |
|---|---|
| `pa_cmp` / `pa_mvm` | Competência (AAAAMM) e mês de movimento/processamento. |
| `idademin` / `idademax` | Faixas etárias permitidas para o procedimento. |
| `pa_cnpjcpf` / `pa_cnpjmnt` | Identificação do prestador/mantenedora. |
| `pa_cbocod` | Código CBO do profissional executante. |
| `nome_proced` | Nome do procedimento. |
| `pa_cidsec` / `pa_cidcas` | CID secundário e associado. |
| `pa_qtdpro` / `pa_qtdapr` / `pa_pmdf` | Quantidade produzida, aprovada e limite máximo diário de faturamento. |
| `pa_valpro` | Valor produzido para pagamento. |
| `pa_tpfin` / `pa_subfin` / `pa_gestao` | Tipo/subtipo de financiamento e gestão. |
| `pa_docorig` / `pa_autoriz` / `pa_catend` / `pa_motsai` / `pa_indica` | Colunas administrativas e de faturamento (BPA/APAC). |

## 3. Colunas Específicas: SIH (Hospitalar)

Focadas em internações (AIH), custos hospitalares e desfechos.

| Coluna | Descrição |
|---|---|
| `n_aih` | Número da AIH (identificador da internação). |
| `cgc_hosp` / `cnpj_mant` | Identificação da unidade hospitalar e mantenedora. |
| `diag_secun` / `diagsec1` ... `diagsec9` | Diagnósticos secundários da internação. |
| `dias_perm` / `qt_diarias` | Tempo de permanência e quantidade de diárias. |
| `val_sh` / `val_sp` | Serviços hospitalares vs. serviços profissionais. |
| `val_uti` / `val_uci` | Custos com UTI e unidade intermediária. |
| `dt_inter` / `dt_saida` | Data de internação e data de saída. |
| `morte` | Indicador de óbito durante a internação. |
| `proc_solic` | Procedimento solicitado. |
| `cobranca` / `gestao` / `financ` / `faec_tp` / `aud_just` / `sis_just` / `sequencia` | Campos administrativos/auditoria e financiamento. |

## 4. Colunas Derivadas (Pipeline)

Criadas no `transform.py` para padronização analítica.

| Coluna | Descrição |
|---|---|
| `idade_paciente` | `pa_idade` (SIA) ou `idade` (SIH). |
| `sexo_paciente` | `pa_sexo` (SIA) ou `sexo` (SIH), normalizado para `M` (código `1`) e `F` (código `3`); valores `0`, `9` e inválidos viram `null`. |
| `raca_cor_paciente` | `pa_racacor` (SIA) ou `raca_cor` (SIH), padronizado para códigos: `01` (Branca), `02` (Preta), `03` (Parda), `04` (Amarela), `05` (Indígena), `99` (Sem Informação). |
| `etnia_paciente` | `pa_etnia` (SIA) ou `etnia` (SIH), código de etnia indígena unificado (IBGE/FUNAI, 4 dígitos), aplicável quando raça/cor = `05`. |
| `cod_munic_residencia` | `pa_munpcn` (SIA) ou `munic_res` (SIH), padronizado para código IBGE de 6 dígitos (sem DV). |
| `cod_munic_estabelecimento` | `pa_ufmun` (SIA) ou `uf_zi` (SIH), padronizado como string de 6 dígitos; no SIH, valores `XX0000` podem indicar UF/gestão estadual (não município físico). |
| `cnes_estabelecimento` | `pa_coduni` (SIA) ou `cnes` (SIH), padronizado como string de 7 dígitos (CNES). |
| `cod_procedimento` | `pa_proc_id` (SIA) ou `proc_rea` (SIH), padronizado para código SIGTAP de 10 dígitos (com zero à esquerda). |
| `cid_principal` | `pa_cidpri` (SIA) ou `diag_princ` (SIH), normalizado em padrão CID-10 (maiúsculo, sem ponto, 3-4 caracteres válidos). |
| `custo_total` | `pa_valapr` (SIA) ou `val_tot` (SIH). |
| `competencia_ano_mes` | `pa_cmp` (SIA) ou `ano_cmpt + mes_cmpt` (SIH), no formato `AAAAMM` (com ajuste de ano SIH quando vier com 2 dígitos). |
